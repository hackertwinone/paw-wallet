"No recopilamos, almacenamos ni transmitimos ninguno de tus datos personales a servidores externos."

Introducción

Paw Wallet se compromete a proteger tu privacidad. Esta Política de Privacidad explica cómo manejamos la información cuando utilizas nuestra aplicación de iOS. La privacidad es un principio fundamental — toda la información de tus mascotas, registros de salud, fotos y documentos se almacena exclusivamente en tu dispositivo mediante el framework seguro SwiftData de Apple.

Almacenamiento de Datos

Qué se almacena localmente en tu dispositivo

  • Perfiles de mascotas (nombres, especies, razas, fotos)
  • Registros de salud (vacunas, visitas veterinarias, notas médicas)
  • Recordatorios y notificaciones
  • Fotos y archivos adjuntos
  • Preferencias del usuario y configuración de idioma

Cómo se almacena

Todos los datos utilizan el framework SwiftData de Apple, protegidos por la seguridad de tu dispositivo — código de acceso, Face ID o Touch ID. Los datos se incluyen en las copias de seguridad de tu dispositivo mediante iCloud o iTunes. No tenemos acceso a tus datos y no podemos recuperarlos si se pierden.

Permisos que Solicitamos

Servicios de Ubicación

Solo para mostrar clínicas veterinarias cercanas. Nunca recopilamos ni almacenamos tu ubicación. Los datos del mapa son proporcionados por Apple Maps.

Biblioteca de Fotos

Para agregar fotos de mascotas y guardar documentos. Las fotos nunca se cargan ni transmiten — se almacenan solo en tu dispositivo.

Cámara

Para tomar fotos de mascotas o documentos dentro de la app. Nada se carga ni transmite a ningún lugar.

Notificaciones

Para recordatorios de vacunas y citas veterinarias. Todas las notificaciones son locales — generadas en tu dispositivo sin servidores externos.

Servicios de Terceros

Apple Maps

La función "Encontrar Veterinarios" utiliza Apple Maps para mostrar la ubicación de clínicas veterinarias. Al usar esta función, aplica la política de privacidad de Apple. Apple puede recibir tus consultas de búsqueda y ubicación — nosotros no recibimos esta información.

No integramos ningún otro servicio de terceros, herramientas de analíticas ni plataformas publicitarias.

Exportación y Eliminación de Datos

Exportar tus datos

Puedes exportar toda la información de tus mascotas en cualquier momento en formato PDF (historial de salud completo) o ZIP (registros más todas las fotos y documentos) — sin restricciones ni limitaciones.

Eliminar tus datos

Elimina mascotas, vacunas o visitas de forma individual dentro de la app, o elimina la aplicación completa de tu dispositivo. Una vez eliminados, los datos no pueden recuperarse a menos que se restauren desde una copia de seguridad del dispositivo.

Privacidad de Menores

Paw Wallet no recopila a sabiendas información de menores de edad. La app tiene clasificación 4+ y es segura para todas las edades. Dado que no recopilamos ningún dato, no existe riesgo para la privacidad de los menores.

Seguridad

Todos los datos utilizan el framework seguro SwiftData de Apple y están protegidos por las características de seguridad de iOS. No hay transmisión de datos sensibles por la red ni vulnerabilidades del lado del servidor — porque no existe ningún servidor.
